# 12. Plantillas operativas — Índice

Plantillas de uso directo en cliente. Todas son **borradores técnicos**: el cliente o su asesor jurídico valida antes de publicación oficial.

## Contenido

| Archivo | Uso | Cuándo |
|---------|-----|--------|
| [`dpia-template.md`](./dpia-template.md) | Evaluación de Impacto en Protección de Datos | Cuando el checklist 11.A da DPIA obligatoria |
| [`clausula-informativa.md`](./clausula-informativa.md) | Texto reusable Art. 13 RGPD para formularios | En toda captura de datos (web, papel, app) |
| [`registro-actividades-tratamiento.md`](./registro-actividades-tratamiento.md) | RAT mínimo Art. 30 RGPD | Documento base. Antes que cualquier IA. |

## Reglas de uso

1. **Adaptar siempre al cliente**. Estas plantillas son esqueleto, no documento final.
2. **Validación legal obligatoria** antes de publicar como documento oficial del cliente.
3. **Versionar**: cada cambio significativo, nueva versión + fecha + responsable.
4. **Vincular al RAT**: cada DPIA y cada cláusula informativa debe poder rastrearse a un tratamiento del RAT.

## Plantillas oficiales de referencia

- **AEPD — Gestión Riesgo y Evaluación de Impacto** (herramienta gratuita): https://www.aepd.es/guias
- **AEPD — Facilita_RGPD** para PYMEs de bajo riesgo: https://www.aepd.es/herramientas/facilita

> [!NOTE] Si el cliente entra en perfil de **Facilita_RGPD** (PYME, datos básicos, sin perfilado, sin sensibles), usá esa herramienta antes que estas plantillas. Es lo que la AEPD reconoce como suficiente para ese perfil.
